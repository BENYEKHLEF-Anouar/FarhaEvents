# FarhaEvents – Gestion des Événements pour l’Association Farha

**FarhaEvents** est une application web développée en **PHP** permettant à l’association **Farha** de gérer efficacement ses événements selon les **salles disponibles** et les **types de tickets proposés** (normal ou réduit).  
Elle offre également aux utilisateurs la possibilité de **consulter leur profil**, **visualiser l’historique de leurs participations**, et **mettre à jour leurs informations personnelles**.

---

## Fonctionnalités principales

### Authentification
- Page de connexion
- Page d’inscription 
- Système de session utilisateur

### Gestion des événements
- Ajout, modification et suppression d’événements  
- Association des événements à des salles spécifiques  
- Définition des types de billets : **normal** et **réduit**  
- Limitation de la capacité par salle

### Réservation et participation
- Réservation de billets selon le type choisi  
- Vérification de la disponibilité en fonction de la salle  
- Affichage des événements **passés** et **à venir**

### Espace utilisateur
- Affichage du profil utilisateur  
- Historique des événements réservés ou assistés  
- Modification des données personnelles (nom, email, mot de passe)

---

## Technologies utilisées

- **Langage** : PHP (procédural avec structuration par fonctions)
- **Base de données** : MySQL
- **Frontend** : HTML / CSS / JavaScript
